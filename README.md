# 慧思智学平台

**以学生画像为起点，驱动个性化学习路径的智能教学系统。**

慧思智学平台是一个可本地部署的教学智能体系统：后端用 FastAPI 提供业务接口与多进程 Agent 编排，前端用 Vue 3 提供 11 个业务页面，工具层通过 MCP 协议暴露 9 个能力供智能体自动发现与调用，云端部分依托华为云 AgentArts 完成智能体托管、网关接入、知识库检索与效果评估。

项目当前以「课程学习」为典型场景（《软件需求分析与建模》），但数据层、编排层与工具层是场景无关的，换课程只需替换知识语料与岗位图谱。

---

## 它解决什么问题

传统教学系统的推荐逻辑往往停留在「你看过什么」这类行为统计上，回答不了三个更本质的问题：

1. **这个学生现在到底弱在哪？** —— 需要从答题、复习、提问的行为里重建能力画像，而不是只统计正确率。
2. **下一步该学什么、为什么是它？** —— 需要把画像、岗位能力要求、知识依赖关系三者对齐，给出可解释的推送理由。
3. **学完之后有没有变好？** —— 需要闭环：诊断 → 干预 → 复测 → 策略进化，而不是一次性推荐。

平台的解法是把这些拆成**各司其职的 Agent 角色**，用一条可观测的编排流水线串起来，每个结论都能回溯到具体的工具返回数据。

## 核心特性

- **六维学生画像**：学习风格、知识基础、认知风格、目标导向、学习节奏、元认知，每维带 confidence 与证据条数，不做无依据的标签。
- **真实多进程编排**：一次完整编排启动 7 个独立进程、完成 9 步工具调用（`controller` / `profile` / `knowledge` / `path` / `diagnose` / `update` / `review`），进程隔离，可观测、可复现。
- **MCP 工具层**：9 个工具通过 MCP 协议对外暴露，云端网关自动发现，无需手工登记工具清单。
- **平台知识库检索**：华为云 AgentArts 知识库（pangu_embedding 向量化 + pangu_rerank 精排），语义检索命中带分值。
- **岗位能力匹配**：结构化岗位画像 + 岗位图谱，做能力项与课程知识点的映射。
- **学习闭环**：练习诊断 → 错题归因 → 路径调整 → 效果评估 → 策略进化，五步留下可查证据。
- **效果评估**：平台内置评测集（8 条）与 LLM 评估器，实测 8/8 成功、均分 0.76。

## 架构

```
┌──────────────────────────────────────────────────────────┐
│  前端（Vue 3 + Vite，11 个页面）                          │
│  首页 / 画像 / 工坊 / 知识图谱 / 多模态 / 练习 / 路径     │
│  辅导 / 评估 / 编排可视化                                 │
└───────────────────────────┬──────────────────────────────┘
                            │ REST + SSE
┌───────────────────────────▼──────────────────────────────┐
│  后端（FastAPI，98 个接口）                               │
│  ├─ 业务服务层：画像 / 路径 / 练习 / 评估 / 知识           │
│  └─ 编排引擎：多进程角色调度 + 运行期 trace               │
└───────────────────────────┬──────────────────────────────┘
                            │ MCP (streamable-http)
┌───────────────────────────▼──────────────────────────────┐
│  MCP 工具层（FastMCP，9 个工具）                          │
│  get_student_profile / get_role_competency /               │
│  get_project_status / search_knowledge /                   │
│  get_exercise_session / submit_exercise_answer /           │
│  get_wrong_book / get_learning_evaluation /                │
│  add_learning_branch                                       │
└───────────────────────────┬──────────────────────────────┘
                            │
┌───────────────────────────▼──────────────────────────────┐
│  华为云 AgentArts（可选，云端增强）                        │
│  智能体运行时 / MCP 网关 / 平台知识库 / 记忆库 / 评估      │
│  模型：deepseek-v4-flash（MaaS 预置服务）                  │
└──────────────────────────────────────────────────────────┘
```

**一次编排的 9 步**（可观测、每个角色一个独立进程）：

| 步骤 | 角色 | 工具调用 |
|---|---|---|
| 1 | controller | 分发任务、汇总结果 |
| 2 | profile | `get_student_profile` |
| 3 | knowledge | `search_knowledge` |
| 4 | path | `get_project_status` |
| 5 | diagnose | `get_exercise_session` |
| 6 | diagnose | `submit_exercise_answer` |
| 7 | update | `add_learning_branch` |
| 8 | review | `get_wrong_book` |
| 9 | review | `get_learning_evaluation` |

## 快速开始

完整步骤见 [`05_源码/README_源码包说明.md`](05_源码/README_源码包说明.md)，最小路径：

```powershell
cd 05_源码\01_主工程
.\安装依赖.ps1          # 安装 Python 与前端依赖（需联网）
.\启动源码.bat          # 一键启动后端 + 前端
```

启动后：

- 后端接口文档：`http://127.0.0.1:8000/docs`
- 健康检查：`http://127.0.0.1:8000/api/health`
- 前端页面：`http://127.0.0.1:5173/`

**不配模型密钥也能跑**：系统内置 `demo_mode`，AI 文本走演示模板，其余业务（画像、路径、诊断、评估、编排）全部可用真实数据。

要接真实模型，复制 `backend/.env.example` 为 `backend/.env`，填 MaaS 的 API Key 即可。

验证编排是否真的跑起来了：

```powershell
cd 05_源码
python scripts\eval\test_multi_agent_real.py
# 期望：9 步全部 ok，输出 7 个互不相同的进程号
```

## 已知边界

- 演示数据是**构造的 demo 学生**（`student_id=demo`），没有接入任何真实学生数据；接真实数据前需完成授权与脱敏。
- 本地知识检索是词袋余弦实现，向量检索能力在平台知识库侧（`ict-course-kb`）。
- 多 Agent 是**运行时容器内的自研进程编排**，没有使用平台控制台的「多智能体」页签（平台 SDK 未提供 handoff / subagent 原语）。
- 云端资源（智能体运行时、网关 Target、平台知识库、评估任务）位于作者自己的华为云账号内，第三方无法直接访问，需要按文档自行重建。
