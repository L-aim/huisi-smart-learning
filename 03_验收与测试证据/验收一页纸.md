## 五之二、多 Agent 真多进程验收（已实测通过，2026-10-17）

```powershell
$py = 'python'
cd '01_主工程\scripts\eval'
# pydantic_core 是 cp312 二进制，必须用这个 3.12 解释器（本机默认 python 是 3.14 会报 ArgsKwargs）
$env:PYTHONPATH='.\ref\pylibs;.\ref\pylibs2;.\ref\pylibs3'

# 5b.1 假注册表（8 组断言）
& $py test_multi_agent.py
# 预期：RESULT: 27/27 通过 / EXIT=0

# 5b.2 真实九工具（需 pydantic、httpx 与 backend/data 里的 demo 演示数据）
& $py test_multi_agent_real.py
# 预期：OK 9/9 通过，7 个角色 7 个真实进程 / EXIT=0

# 5b.3 接口层（真 ASGI 请求，不监听端口）
cd '01_主工程'
& $py scripts\eval\test_multi_agent_api.py
# 预期：HTTP 200 / DISTINCT_WORKER_PIDS 7 / RESULT PASS / EXIT=0
```

**判据（可被推翻，不是形容词）**：

1. `WORKERS` 里 7 个 pid 互不相同，且都不等于 `PARENT_PID`；
2. `diagnose` 两步同在 `pid=51956`，`review` 两步同在 `pid=31932` → 角色与进程一对一；
3. 三处传值逐字对上：`weaknesses[0]` → `search_knowledge.query`、`questions[0].id` → `submit_exercise_answer.question_id`、`current_stage.id` → `add_learning_branch.knowledge_node_id`；
4. 接口层 `POST /api/orchestration/multi-agent` 返回 `available=true / runtime=multiprocess / ok=true`，且 `workers` 7 个 pid 互不相同（实测 674ms）。

**注意**：多进程要靠命名管道，受限沙箱下会报 `PermissionError: [WinError 5] 拒绝访问`，跑之前需放宽一次权限；这不是代码缺陷，Linux 容器内无此限制。`spawn` 会重跑入口脚本，所有脚本都要有 `if __name__ == "__main__"` 守卫（Linux 容器用 `fork` 规避这一条）。
