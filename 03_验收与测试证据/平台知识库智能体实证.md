## 五、试运行三条问答（原文）

### 问题 1：软件需求分析与建模的入门视频建议看多久？

> 建议入门视频看 10–20 分钟。
>
> 根据教学视频推荐资料，入门视频的「建议时长」明确标注为 10-20 分钟，推荐理由是「先建立直观概念和基本术语，适合课前预习」。（来源：《软件需求分析与建模-教学视频推荐.md》）
>
> 此外，资料中还建议「先看入门视频建立概念，再看案例视频完成迁移」，并且每看完一个视频要记录 3 个关键词和 1 个仍然不懂的问题。（来源：同一文档的「使用建议」部分）

### 问题 2：我连续答错三次了，接下来该怎么办？

> 系统会自动切换为「教师模式」，为你给出详细解释，并询问是否需要从头讲解该知识点。
>
> 根据《软件需求分析与建模·通用答疑语音辅导方案》中的失败兜底方案，当出现「学生连续 3 次回答错误」时，应对方案是：切换为『教师模式』：系统给出详细解释，并建议：「需要我为你从头讲解这个知识点吗？请说『要』或『不要』。」（来源：《软件需求分析与建模-通用答疑语音辅导方案.md》）

### 问题 3：用例图里 include 和 extend 有什么区别？

> 现有资料里没有讲到这个点。
>
> 我在知识库中未检索到关于用例图中 include 与 extend 区别的相关内容，因此无法为你提供区分说明。建议你查阅教材中用例图的章节，或在课堂答疑时向老师提问。

### 为什么这三条算硬证据

1. **答案里有资料原文才有的数字**（10–20 分钟、20–40 分钟）和**原话**（「需要我为你从头讲解这个知识点吗」），不是通用常识能编的。
2. **每条都带来源文件**，说明「引用和归属」真的把切片引用带进了回答。
3. **第三问模型本可以自己讲清 include/extend，但它拒答了**——说明「只依据检索结果」这条约束真的在起作用，而不是走个形式。这一条比前两条更能说明「知识边界是被检索结果约束的」。

## 六、平台的三条硬限制（踩过才知道）

1. **没有对外检索 API**：SDK `agentarts/sdk/` 下只有 `gateway / identity / integration / memory / runtime / service`，没有知识库模块；控制台知识库的「更多」菜单只有 修改配置 / 编辑 / 复制 / 查看引用 / 删除，没有「知识库地址」或 API Key。
   → 高代码 agent（我们云端那个 `ict-career-agent`）**无法**直接调平台知识库。
2. **第三方知识库的方向是反的**：官方《第三方通用知识库接入规范》要求**你**实现 `GET /knowledge-bases` 和 `POST /knowledge-bases/retrieve` 供 AgentArts 调用，不是给你一个能调的接口。
3. **部署成 API 需要 MaaS 模型 API Key**：点「部署」后弹窗要求填模型 API Key，否则「目前 MaaS 模型未配置授权，将无法使用 API 调用大模型」。本作品**只提交版本、不部署**，避免产生费用；试运行用的是平台赠送的调试 Tokens。

## 八、边界（答辩时别说错）

- 平台知识库**只服务平台内智能体**，不服务我们的高代码 agent；两条通路是并列的，不是串联的。
- 该单智能体**未部署**，所以没有公网 endpoint，也没有 API 调用截图；证据止于「配置 + 版本 + 试运行」。
- 库里只有 **2 篇文档 / 13 条切片**，是演示级语料，不是课程全量知识；0.05 分那条正说明覆盖面很窄。
- 「多智能体」页签尚未使用——平台确实有多智能体画布能力，但本项目云端多 Agent 是**容器内多进程**实现，两者不是同一件事。
